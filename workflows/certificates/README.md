## الهدف

إنشاء شهادات الحاضرين المستحقين وإرسالها بالبريد الإلكتروني مع حفظ النسخ وحالة الإرسال.

## المدخلات والإعدادات المطلوبة

- قائمة الحاضرين المستحقين للشهادات وأسماؤهم وبريدهم الإلكتروني.
- قالب الشهادة المعتمد والبيانات المطلوبة لتعبئته.
- طريقة إنشاء ملفات PDF ومكان حفظها وقالب البريد.

## السلوك المطلوب عند اكتمال التطوير

1. قراءة قائمة المستحقين المعتمدة.
2. إضافة اسم كل مشارك إلى قالب الشهادة.
3. إنشاء ملف PDF منفصل لكل شهادة.
4. حفظ نسخة من الشهادة.
5. إرسال الشهادة إلى البريد الإلكتروني الصحيح وتسجيل حالة الإرسال.

## المخرجات

شهادات PDF محفوظة وسجل يوضح حالة الإرسال ورابط شهادة كل مشارك.

## البدء والتسليم

1. استورد `workflow.json` إلى نسخة n8n المحلية. الملف الحالي قالب فارغ وغير مفعّل لبدء العمل؛ لا ينفذ الوظائف المذكورة أعلاه.
2. ابنِ الخطوات واربط الخدمات باستخدام بيانات تجريبية.
3. وثّق أسماء الخدمات والإعدادات المطلوبة هنا، دون نسخ القيم السرية.
4. اختبر الحالات أدناه، ثم صدّر الأتمتة واستبدل القالب بالنسخة المطورة.
5. ارفع التعديلات في فرع خاص بالنظام وافتح Pull Request للمراجعة.

إذا احتاج النظام أكثر من Workflow، يُحفظ كل واحد في ملف JSON مستقل باسم واضح داخل هذا المجلد، ويُشرح ترتيب تشغيلها هنا.

## حالات التحقق قبل التسليم

- اختبار الاسم العربي الطويل والتأكد من وضوحه داخل القالب.
- مطابقة الشهادة والبريد مع المشارك الصحيح.
- اختبار بريد غير صالح وفشل إرسال وإعادة المحاولة.
- التحقق من عدم تكرار إرسال الشهادة عند إعادة التنفيذ.

## الربط مع الأنظمة الأخرى

استخدم `event_id` لتمييز الفعالية و`participant_id` لتمييز المشارك. اتفق مع مسؤولي الأنظمة الأخرى على أسماء الحقول والحالات قبل الربط.
