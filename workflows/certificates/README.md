# إصدار الشهادات

**Certificate Issuance**

| البند | القيمة |
|---|---|
| الحالة | جاهز للمراجعة |
| المسؤول | فيصل الناصر |
| المراجع | يُحدد لاحقًا |
| ملف الأتمتة | [workflow.json](workflow.json) |

## الهدف

إرسال شهادات الحاضرين المستحقين بالبريد الإلكتروني تلقائيًا، مع تسجيل حالة الإرسال ورابط شهادة كل مشارك.

## المدخلات والإعدادات المطلوبة

- **قائمة الحاضرين** في Google Sheet، تبويب اسمه `attendees` بالأعمدة:

  | name | email | certificate_file | status | sent_at | note | certificate_link |
  |---|---|---|---|---|---|---|

  `status` و `sent_at` و `note` و `certificate_link` تُترك فاضية، والنظام يعبّيها. نموذج: [test-sheet.csv](test-sheet.csv)
- **مجلد الشهادات** في Google Drive، فيه ملف PDF لكل مشارك. اسم الملف لازم يطابق عمود `certificate_file` حرفيًا مع `.pdf`.
- **حساب Google** (حساب النادي) مربوط في n8n، وهو الحساب اللي يرسل الإيميلات.
- **مربع Settings** داخل الـ Workflow:

  | الحقل | الوصف |
  |---|---|
  | `sheet_url` | رابط جدول الحاضرين |
  | `sheet_name` | اسم التبويب (`attendees`) |
  | `folder_id` | رقم مجلد الشهادات (الجزء بعد `/folders/` في الرابط) |
  | `email_subject` | عنوان الإيميل |
  | `event_name` | اسم الفعالية كما يظهر في الرسالة |
  | `sender_name` | اسم المرسل وتوقيع الرسالة |

> الشهادات حاليًا تصل جاهزة من علم (PDF لكل مشارك)، فالنظام يربطها ويرسلها ولا يولّدها من قالب. توليد الشهادات من قالب بالاسم يمكن إضافته لاحقًا كمرحلة قبل الإرسال إذا احتجناه.

## السلوك المطلوب عند اكتمال التطوير

1. قراءة قائمة الحاضرين من الجدول.
2. تجاهل من حالتهم `sent` لمنع التكرار.
3. البحث عن ملف شهادة كل مشارك في مجلد Drive بالاسم.
4. إرسال الشهادة مرفقة بإيميل HTML عربي من Gmail، مع انتظار 3 ثوانٍ بين كل رسالة.
5. تسجيل النتيجة في الجدول:
   - `sent` مع وقت الإرسال ورابط الشهادة
   - `file not found` إذا ما وُجد ملف بنفس الاسم
   - `failed` مع سبب الخطأ إذا فشل الإرسال

## المخرجات

- إيميل لكل مشارك فيه شهادته.
- الجدول نفسه يصير سجل الإرسال: الحالة والوقت ورابط الشهادة لكل مشارك.

## البدء والتسليم

1. شغّل n8n محليًا:
   ```
   docker run -d --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n
   ```
   وافتح `http://localhost:5678`
2. **Create Workflow** ← **⋯** ← **Import from File** ← `workflow.json`
3. عبّي مربع **Settings**.
4. اربط حساب Google في مربعات Google Sheets و Drive و Gmail (الخطوات تحت).
5. جرّب أول على جدول تجريبي بإيميلاتك، وبعدها اضغط **Execute** على القائمة الحقيقية.

### ربط حساب Google

1. في [Google Cloud Console](https://console.cloud.google.com) بالحساب المرسل: مشروع جديد ← فعّل `Gmail API` و `Google Sheets API` و `Google Drive API`.
2. **Google Auth Platform**: Audience = External، وأضف الحساب في **Test users**.
3. **Clients** ← Create client ← Web application ← في **Authorized redirect URIs**:
   ```
   http://localhost:5678/rest/oauth2-credential/callback
   ```
4. في n8n: Credential ← Create new ← الصق Client ID و Client Secret ← Sign in with Google.

> Google Cloud يتطلب تفعيل التحقق بخطوتين على الحساب.
> في وضع Testing ينتهي الربط بعد 7 أيام تقريبًا، فأعد Sign in قبل الإرسال الحقيقي.

## حالات التحقق قبل التسليم

| الحالة | النتيجة |
|---|---|
| إرسال 3 شهادات لـ 3 إيميلات مختلفة | ✅ وصلت كلها، والحالة `sent` |
| مطابقة الشهادة مع الإيميل الصحيح | ✅ الربط بعمود `certificate_file` |
| ملف شهادة غير موجود | ✅ الحالة `file not found` ويكمل الباقي |
| إعادة التشغيل بعد الإرسال | ✅ ما ينرسل لأحد مرتين |
| فشل الإرسال وإعادة المحاولة | الحالة `failed` مع السبب، وإعادة التشغيل تعيد المحاولة لهم فقط |
| الاسم العربي الطويل داخل الشهادة | لا ينطبق حاليًا (الشهادات تصل جاهزة) |

> الإيميل الموجود لكن غير صحيح (مثل خطأ إملائي في الدومين) يُقبل من Gmail ويُسجّل `sent`، ثم يرجع كـ Bounce في صندوق الحساب المرسل. راجع الصندوق بعد الإرسال.

## الربط مع الأنظمة الأخرى

الجدول حاليًا مستقل. إذا اعتمدنا `event_id` و `participant_id` من نظام التسجيل، نضيفها كأعمدة في الجدول ونسمّي ملفات الشهادات بـ `participant_id` بدل الاسم، لأن الربط بالرقم أدق من الربط بالاسم.

## ملاحظات التنفيذ

- **الخدمات**: n8n (Docker)، Google Sheets، Google Drive، Gmail.
- **مسار الـ Workflow**: Start ← Settings ← Read Sheet ← Not Sent Yet ← Loop ← Find Certificate ← File Found? ← Download ← Send Email ← Mark Sent / Mark Failed / Mark Not Found.
- **تعديل نص الرسالة**: مربع **Send Email** ← حقل Message. والعنوان والتوقيع من **Settings**.
- **تغيير الحساب المرسل**: اربط حساب Google ثاني في Credential حق Gmail.
- **أسماء الملفات**: يفضّل أسماء إنجليزية أو أرقام. الأسماء العربية تشتغل في Drive، لكنها تنكسر لو انضغطت وانفكت في ويندوز.
- **حد Gmail**: تقريبًا 500 إيميل يوميًا للحساب العادي.
- **الأمان**: لا يُرفع Client Secret ولا جداول فيها بيانات حقيقية. مشاركة الجدول والمجلد تكون Restricted.
